# Frontend (11절 화면 구성)

React 프로젝트 예정 위치. 구현할 화면 6개:

- 대시보드 — 접수 건수/유형별 현황/처리지연/우선순위 현황 시각화
- 문의 접수 — 제목/내용/첨부/연락처 입력 (사용자용)
- AI 분석 결과 — 문의유형/담당부서/우선순위/분류근거 표시
- RAG 검색 결과 — 관련 FAQ/규정/매뉴얼 문단 표시
- 답변 초안 편집 — AI 답변 초안 수정 및 최종 답변 저장
- 지식베이스 관리 — FAQ/매뉴얼/공지 업로드 및 임베딩 (관리자용, 문의유형/부서매핑/Rule 관리 탭 포함)

백엔드 API: `POST /inquiries { text }` → 분류/근거/답변초안 포함 응답.
